1 프로젝트 개요

항목내용
서비스명Bitcoin Vanity Address Generator
목적사용자가 원하는 패턴의 비트코인 주소를 브라우저에서 로컬 탐색
아키텍처클라이언트 로컬 생성형 서버 미전송
기술 스택HTML5 + Vanilla CSS + JavaScript (Web Worker)
외부 라이브러리bitcoinjs-lib, noble-secp256k1, bech32, CryptoJS
🔒 핵심 원칙: 개인키는 브라우저 내부에서만 생성되며, 서버로 절대 전송되지 않습니다.

4 핵심 아키텍처

4-1. 생성 흐름

🎲 난수 32바이트
→
🔑 ECPair 생성
→
📝 공개키 파생

🏠 주소 생성

🔍 패턴 매칭

상세 흐름

  1. crypto.getRandomValues() → 32바이트 CSPRNG 난수 생성
  2. bitcoin.ECPair.fromPrivateKey(Buffer) → 키페어 생성
  3. 타입별 주소 파생 (P2PKH / P2SH / P2WPKH / P2TR)
  4. 패턴 매칭 검사 (prefix 또는 contains)
  5. 일치 시 WIF + hex + pubkey + 주소 반환
  6. 불일치 시 1번으로 반복

9 보안 설계

원칙구현
서버 미전송모든 연산이 Web Worker 내부에서 실행
개인키 숨김주소만 1차 표시 → 모달 경고 후 노출
메모리 정리"메모리 정리" 버튼 → 변수 null + UI 초기화
CSPRNGcrypto.getRandomValues() 우선
다운로드 보안Blob → 일회성 URL → 즉시 revoke
⚠️ 이 개인키를 잃어버리면 주소를 다시 사용할 수 없습니다.
⚠️ 개인키를 다른 사람과 공유하면 자산 통제권도 함께 넘어갑니다.
⚠️ 공용 PC에서는 사용하지 마세요.
